# 🎬Movie Recommendation Engine

**Discover movies that match your mood!** An AI-powered movie recommendation web application that understands your emotions and suggests the perfect films to watch.

## 📌 Project Overview
This project is a **Movie Recommendation Tool** developed as part of the DevCom Developer Assignment.  
The website allows users to search for movies based on:
- Movie name
- Actor name
- User mood (using AI)

Users can view detailed movie information and explore similar movie recommendations.

### 3️⃣ Movie Details Popup
Clicking on any movie displays a **popup modal** showing:
- Movie poster
- Title
- Year
- IMDb rating
- Genre
- Cast 
- Plot summary

### 🔧 How I Built This Project

## 1️⃣ Understanding the Problem Statement
The first step was to understand the assignment requirements
I broke the problem into three main parts:
1. User Interface (UI)
2. Movie data fetching
3. Intelligent recommendation logic

## 2️⃣ Designing the User Interface
I started with a simple HTML structure:
- Header with project title
- Search bar for user input
- Results section for displaying movies
- Popup modal for detailed movie information

For styling:
- Used **pure CSS** instead of frameworks to better understand layout fundamentals
- Added a background image with a dark overlay to improve text readability

## 3️⃣ Implementing Basic Movie Search
 I implemented basic movie search functionality:
- Used the **OMDB API** to fetch movie data dynamically
- Used JavaScript `fetch()` to retrieve movie lists based on user input

## 4️⃣ Implementing Similar Movie Recommendations
To improve discovery:
- Extracted the primary genre of the selected movie
- Used that genre to fetch and display similar movies
